# Empresarial

| Característica            | Valor                                                                          |
| ------------------------- | ------------------------------------------------------------------------------ |
| `ProductCode`             | `businessproperty`                                                             |
| Id do produto             | `18001`                                                                        |
| Segurado                  | Pessoa Física ou Pessoa Jurídica                                               |
| Itens                     | 1 ou mais, cada um com endereço, atividade, classe de construção e coberturas |
| Tipos de cotação          | Seguro novo, renovação congênere e renovação Mitsui                            |

[**Consultas**](consultas.md)**:**

* Atividades, classe de construção, coberturas e perfil de risco do item.

[**Calcular**](calcular.md)**:**

* Realiza o processo de salvamento e cálculo do contrato.

[**Proposta**](proposta.md)**:**

* Realiza a geração de proposta, com dados do segurado, beneficiários, inspeção e pagamento.

{% hint style="info" %}
[Transmissão](../transmissao.md) e [Cancelar proposta](../cancelar-proposta.md) são comuns a todos os produtos.
{% endhint %}
